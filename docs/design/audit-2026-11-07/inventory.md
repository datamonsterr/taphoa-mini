## Findings

Each ID is counted once even if it affects several boards. Severity: 10 major, 0 minor. Tests below are proposed assertions, not executed.

- **G1 major — extra persistent banner moves all inventory variants down.** Board starts with the handle; the app shows `2 sản phẩm sắp hết hàng` above it. `apps/mobile/src/app/(shop)/_layout.tsx:21`; `docs/design/canvas/Inventory.dc.html:20`. Playwright `inventory starts with handle`: seed low stock and assert the handle is the first visible control and no low-stock banner precedes it.
- **G2 major — default Inventory always has add buttons.** Board Inventory has no plus; app always passes `onAdd` (`apps/mobile/src/features/inventory/InventoryScreen.tsx:69`, `apps/mobile/src/components/ui/ProductTile.tsx:92`); InventorySell deliberately depicts plus buttons. RNTL `inventory default has no add controls`: assert `queryByRole('button', {name: /Thêm .* vào giỏ/})` is null in the non-selling state.
- **G3 major — elder cart pill is 56px instead of 80px.** Board `docs/design/canvas/InventoryElder.dc.html:83` specifies 80px and 24px text; app reuses 56px/18px pill (`apps/mobile/src/components/camera/CartPill.tsx:64`, `:105`). RNTL `elder cart pill size`: with elder mode and an item, assert pill height 80 and total fontSize 24.
- **G4 major — product stat layout differs.** Board `docs/design/canvas/Product.dc.html:33` stacks icon above value in 102px cards; app places them inline in shorter cards (`apps/mobile/src/features/product/ProductScreen.tsx:308`). The board also stacks name and price while app uses a wrapping row (`:298`); fixture's long name happens to wrap. RNTL `product board hierarchy`: assert title container flexDirection is column and each stat flexDirection is column.
- **G5 major — units editor adds an extra action while editing.** Board displays edit form followed by delete and explanatory copy; app also displays `Thêm đơn vị` below the form (`apps/mobile/src/features/product/UnitsEditor.tsx:159`; board `docs/design/canvas/ProductUnits.dc.html:5`). RNTL `editing unit actions`: open an existing unit and assert `queryByRole('button', {name: 'Thêm đơn vị'})` is null.
- **G6 major — stock filter is a separate wrapped row rather than a header select.** Board places `Lọc tồn kho` select beside title (`docs/design/canvas/Stock.dc.html:22`); app renders four chips below the segment, wrapping the fourth at 390px (`apps/mobile/src/features/stock/StockScreen.tsx:42`, `:53`). Playwright `stock filter placement`: assert a select labelled `Lọc tồn kho` is visible in the title row and offers all four options.
- **G7 major — stock daily sales text missing.** Board rows say e.g. `Ngưỡng 5 · bán 6/ngày`; app shows only `Ngưỡng 5` (`apps/mobile/src/features/stock/StockScreen.tsx:138`, `apps/mobile/src/features/stock/strings.ts:11`). RNTL `stock daily rate`: given threshold 5 and rate 6, assert `Ngưỡng 5 · bán 6/ngày` is visible.
- **G8 major — enroll sheet hides the intended camera area.** Board top is y=104 with scrim and visible preview; populated app sheet starts y≈8 (`docs/design/canvas/Enroll.dc.html:22`, `apps/mobile/src/features/enroll/ProductForm.tsx:34`, `:43`). This also makes the keys larger than the board's 64px. Playwright `populated enroll camera area`: assert sheet top is 104px and preview remains visible at 390×844.
- **G9 major — export uses a bottom sheet rather than the board's page.** Board includes `‹ Báo cáo` and `Bán hàng và khoản chi`; app opens a scrimmed modal without either (`docs/design/canvas/Export.dc.html:5`, `apps/mobile/src/features/dashboard/ExportSheet.tsx:41`). RNTL `export page context`: assert `Bán hàng và khoản chi` and the back-to-Báo cáo control are visible.
- **G10 major — export format and date copy differ.** Board uses visible `Định dạng` select with `CSV` / `Excel (XLSX)`, and labels `Từ ngày`, `Đến ngày`; app shows two radio cards, `XLSX`, and labels with `(YYYY-MM-DD)` (`apps/mobile/src/features/dashboard/ExportSheet.tsx:58`, `:78`; `apps/mobile/src/features/dashboard/transactionStrings.ts:28`). RNTL `export board labels`: assert exact date labels and `Excel (XLSX)` plus visible `Định dạng`.
