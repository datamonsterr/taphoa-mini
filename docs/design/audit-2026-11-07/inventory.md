## Findings

Each ID is counted once even if it affects several boards. Severity: 10 major, 0 minor.

- **G1 major — extra persistent banner moves all inventory variants down.** Board starts with the handle; the app shows `2 sản phẩm sắp hết hàng` above it. `apps/mobile/src/app/(shop)/_layout.tsx:21`; `docs/design/canvas/Inventory.dc.html:20`. Playwright `inventory starts with handle`: seed low stock and assert the handle is the first visible control and no low-stock banner precedes it.
- **G2 major — default Inventory always has add buttons.** Board Inventory has no plus; app always passes `onAdd` (`apps/mobile/src/features/inventory/InventoryScreen.tsx:69`, `apps/mobile/src/components/ui/ProductTile.tsx:92`); InventorySell deliberately depicts plus buttons. RNTL `inventory default has no add controls`: assert `queryByRole('button', {name: /Thêm .* vào giỏ/})` is null in the non-selling state.
- **G3 major — elder cart pill is 56px instead of 80px.** **[FIXED in #327]** Board `docs/design/canvas/InventoryElder.dc.html:83` specifies 80px and 24px text; fixed in PR #327 (`CartPill.tsx:82`, `elderPill: { height: size.tapXl }`, `elderTotal: { fontSize: fontSize[24] }`). Confirmed in capture `inventory-elder-app.png`.
- **G4 major — product stat layout differs.** **[FIXED in #327]** Board `docs/design/canvas/Product.dc.html:33` stacks icon above value in 102px cards and stacks name and price; fixed in PR #327 (`ProductScreen.tsx:307, :313`). Confirmed in capture `product-app.png`.
- **G5 major — units editor adds an extra action while editing.** **[FIXED in #327]** Board displays edit form followed by delete and explanatory copy without `Thêm đơn vị`; fixed in PR #327 (`UnitsEditor.tsx:159`). Confirmed in capture `units-app.png`.
- **G6 major — stock filter is a separate wrapped row rather than a header select.** **[FIXED in #327]** Board places `Lọc tồn kho` select beside title (`docs/design/canvas/Stock.dc.html:22`); fixed in PR #327 (`StockScreen.tsx:62`). Confirmed in captures `seed-stock.png` and `stock-low-app.png`.
- **G7 major — stock daily sales text missing.** **[FIXED in #330, #332]** Board rows say e.g. `Ngưỡng 5 · bán 6/ngày`; added backend `sales_rate` in PR #330 and mobile display in PR #332 (`StockScreen.tsx:180`). Confirmed in capture `stock-low-app.png`.
- **G8 major — enroll sheet hides the intended camera area.** Board top is y=104 with scrim and visible preview; populated app sheet starts y≈8 (`docs/design/canvas/Enroll.dc.html:22`, `apps/mobile/src/features/enroll/ProductForm.tsx:34`, `:43`). Deferred: waits for #301 which rewrites `ProductForm.tsx`.
- **G9 major — export uses a bottom sheet rather than the board's page.** Board includes `‹ Báo cáo` and `Bán hàng và khoản chi`; app opens a scrimmed modal without either (`docs/design/canvas/Export.dc.html:5`, `apps/mobile/src/features/dashboard/ExportSheet.tsx:41`). RNTL `export page context`: assert `Bán hàng và khoản chi` and the back-to-Báo cáo control are visible.
- **G10 major — export format and date copy differ.** **[FIXED in #327]** Board uses visible `Định dạng` select with `CSV` / `Excel (XLSX)`, and labels `Từ ngày`, `Đến ngày`; fixed in PR #327 (`ExportSheet.tsx:63, :85`). Confirmed in capture `export-app.png`.
